# Cat2Link Backend

This is the backend service for the my personal portfolio application, responsible for managing projects, media, and categories. It provides RESTful APIs for admin operations and handles file uploads for media associated with projects.

## Features

- Manage projects, media, and categories
- RESTful APIs for admin operations
- File uploads for media associated with projects
- Data validation and error handling
- Relationship management between projects, media, and categories


## Installation

- Clone the repository: `git clone https://github.com/yourusername/cat2link-backend.git`
- Navigate to the project directory: `cd cat2link-backend`
- Install dependencies: `pip install -r requirements.txt`
- Set up the database: `flask db upgrade`
- Run the development server: `flask run`
